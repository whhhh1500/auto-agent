# Changelog

## v0.1.0-alpha.1 - 2026-09-02

Initial alpha release of Harness Core, an open-source Go foundation for
composable Agents and digital humans.

- Durable sessions, runs, approvals, evaluations, evidence, and SQL storage.
- Capability and profile composition with guarded execution and adapters.
- Linux/Windows amd64 and arm64 build targets.
- Non-root Docker image and PostgreSQL 16 development compose environment.

This is a pre-release. Public API and persistence contracts may change before
the first stable release.
