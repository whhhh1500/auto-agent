# PTC 稳定性与会话恢复实测

承接[重复滚动摘要验证](2026-09-09-summary-rollover-and-evidence.md)。仍为开发样本，不构成全局最优或完整恢复协议的验收。

## 第十八波：带实际效果计数的 PTC 诊断

保持 v5-binding-guidance 工具合同、原 n8 提示、渐进展示及 11 次工具预算。此次加入的观测已在离线验证，不修改程序、参数或失败结果。固定二进制 SHA-256 `6fdf4f0bb30a71eb7319ce9ca93b1729edfead9551b536931e9bae9d3410b9ed`，与第十七波使用的二进制相同。

| 请求模型 | 验收 | 模型轮数 | 输入/输出 token | 实际列表/详情调用 | 预算拒绝 |
| --- | --- | ---: | ---: | --- | ---: |
| Terra | 失败，runtime_get_not_object | 3 | 14,618 / 715 | 1 / 0 | 0 |
| Luna | 通过 | 3 | 14,659 / 582 | 1 / 8 | 0 |

两项编译通过，源码工具集合与两项 binding/digest 都匹配。Terra 的错误出现在首个工具返回之后；数据形状处理失败，没有触发预算拒绝，不能归因为模型轮数不足。Luna 的完整任务通过仍不能消除同版本 Terra 的失败。

本次 composite-literal 扫描不适用（两程序都编译成功），因此没有证据支持将本次失败解释为数组/对象字面量限制。只读语法审核确认放宽 literal 需要递归节点、深度、容器、字符串和运行 arena 约束；本轮没有基于猜测扩展语法。

实际效果计数来自 fixture provider，预算拒绝来自固定结果码。过去仅有聚合事件数的记录不回填本次字段。两个测试退出码分别为 1 和 0，失败成本保留。

## 第十九波：SQLite 关闭重开后的真实会话

从空 Session 开始，第一轮用户提供随机事实并要求 ACK；通过公开 SQLSessionStore Create/Save 持久化，关闭数据库，以同一路径创建新的 SQLite handle/store 后 Load。加载前后事件前缀精确匹配。重建 Runtime 后第二轮仅询问当前事实，问题不含答案；模型消息按角色、来源序号和内容与恢复历史逐项匹配。第二轮再 Save，并再次 Load 后核验最终答案。

固定二进制 SHA-256 `5326639c7f421e6912cc9acfe424a92cbbf8d075f7987751716463c50a1fdc8d`：

| 请求模型 | 验收 | 模型调用 | 已报告输入/输出 token |
| --- | --- | ---: | ---: |
| Terra | 通过 | 2 | 7,223 / 28 |
| Luna | 通过 | 2 | 7,221 / 27 |

两例均确认新数据库句柄、恢复 Session ID、事件前缀、模型历史前缀、第一轮 ACK、最终回答及 SQL 重载后的回答正确；两个 run 的 usage 分别与对应 adapter 调用相等。两测试退出码均为 0。没有用内存事件复制代替 SQL Load。

范围限于已完成普通 Session 的干净关闭/重开及继续对话；不是进程硬杀、未完成工具、未知 provider outcome、native queue repair 或 PostgreSQL 的证据。它也没有证明外部调用方的当前授权刷新，测试使用固定只读 Principal。SQLite 默认同步设置不能据此推出断电耐久性。

离线 SQLite 测试、examples race、modulecheck、vet、汇总器测试与差异检查通过。汇总器已支持独立 SQLite schema，保留失败/不完整 usage，并与 rollover 一起校验调用数和账本完整性字段；它仍不等于远端账单。

## 下一效益对照

现有 n8 工具返回较小，不能代表 PTC 在大中间结果处理中的价值。下一组候选采用相同的 4KiB 无关详情字段，比较自动、强制批量直接、强制 PTC；只在基线策略标签上不同，数据、工具菜单、输出合同和预算一致。fixture 私有配置即可实现，不扩大公开 API。大字段的实际 JSON 总长度必须满足声明的 MaxOutputBytes。

验收先要求同样的八项效果和正确答案，再比较全部 usage、轮次与上下文字节数。不把“PTC 必然更省”设为通过条件，也不将这个新的场景替换已有失败样本。后续实现同时保留 2KiB 成功对照与 4KiB 默认上下文压力；当前进度与提示歧义基线见[大工具结果实测](2026-09-09-large-tool-results.md)。
